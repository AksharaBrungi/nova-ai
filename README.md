# NOVA AI

NOVA AI is an AI-powered assistant built with modern web technologies. It supports conversational AI, document-based question answering, useful tools, and voice interaction.

## Features

* AI Chat Assistant
* Document Upload & RAG-based Q&A
* Text-to-Speech
* Image Understanding
* Calculator & Utility Tools
* Real-time Chat Responses
* Responsive UI

## Tech Stack

* React + TypeScript
* Node.js + Express
* Google Gemini API
* Vite
* Tailwind CSS

## Setup

```bash
npm install
npm run dev
```

Create a `.env` file and add:

```env
GEMINI_API_KEY=your_api_key
```

## Purpose

Built as an AI assistant project demonstrating LLM integration, RAG, tool usage, and modern full-stack development.
